Capture Card Viewer.

Lightweight capture card viewer for Windows — by Quidque Studio

Requirements First Launch Controls Settings Troubleshooting Data & Logs

Requirements

OSWindows 10 or later (64-bit)
HardwareUSB capture card with UVC support
DriversManufacturer drivers if required

First Launch

On first launch you will be asked to select your devices before anything starts.

Video Input — usually listed as "USB Video", "USB Capture", or your capture card's brand name (e.g. "Elgato HD60 S", "AVerMedia Live Gamer").
Audio Input — usually shares the same name as the video input, or follows the same guidelines.

Click Save to confirm your selections. The viewer will start immediately.

Controls

F11 Toggle fullscreen S Open / close settings

Settings

Press S or click Settings in the menu bar to open the settings panel.

Setting Description
Video Input Your capture card's video source
Audio Input Your capture card's audio source
Audio Output Where to send audio. Leave as System Default unless you need a specific output device
Volume Playback volume from 0× to 3×. Values above 1.0 amplify the incoming signal — the default is 1.5×

Click Save to apply. If you changed a device, the stream restarts automatically. Click Close to discard any changes.

Troubleshooting

No devices appear in the dropdown

Make sure the capture card is connected before launching. Open Device Manager and check it appears without errors. Try a different USB port if needed.

Stream disconnects immediately after loading

Another application such as OBS Studio or a browser is most likely already using the device. Close it, then go to Settings → Save to reconnect.

No audio coming through

Confirm the correct Audio Output is selected in Settings, that the volume slider is above zero, and that the source device is actively sending audio to the capture card.

Black screen or frozen frame

Some capture cards require an active incoming signal. Ensure the source device is powered on and outputting video to the capture card.

Data & Logs

All app data is stored locally at:

%LOCALAPPDATA%\capture-card-viewer\
settings.toml Device selections, volume, and display preferences app.log Log output from the most recent session

Settings are saved automatically when the app closes. If settings.toml becomes corrupt, it will be deleted and reset automatically — the setup screen will appear on next launch.
